# oxDNA Aptamer Clamp Project — Context for Claude

## Project Goal
Compute the free energy difference between fully-bonded (bond=6) and fully-separated (bond=0, large mindistance) states of a DNA aptamer stem, with and without a bent duplex "clamp" applying mechanical force. Compare three geometries: pulling clamp, pushing clamp, noclamps reference.

**Why:** Understand how bent duplex geometry mechanically ruptures aptamer stems — relevant to DNA nanotechnology biosensors.

---

## Experimental Fluorescence Kinetics Data

Parallel experimental validation of the simulation predictions. All plots generated by Python scripts in `Report/Ella's Plots/`.

### Assay overview
- FRET-based fluorescence kinetics measured on a plate reader (33 s intervals)
- Aptamer stem carries a FRET donor/acceptor pair; intact stem → high fluorescence
- Stem opening/disruption → FRET loss → fluorescence **decrease**
- Nanodevice (clamp + aptamer) injected at t ≈ 330 s (Lab6) or t ≈ 297 s (Lab3)
- "Switch (nt)" = rod length controlling clamp bend angle; Control = no rod (no clamp force)

### Lab6 — 6 nt stem, 54 nt and 40 nt rods (`lab6_54nt_40ntrods.m`)
Script: `fluorescence_kinetics.py` → `fluorescence_kinetics_push.pdf/svg`, `fluorescence_kinetics_pull.pdf/svg`

3 replicates per condition; mean ± 2 SD shown as shaded band; movmean window = 20.

| Condition | Observation | Interpretation |
|-----------|-------------|----------------|
| **Push + 54 nt** (blue) | Sharp drop ~2.5 → 1.6 ×10⁴ RFU within ~1 h, then plateaus | Pushing clamp ruptures 6 nt stem efficiently |
| **Push + 40 nt** (red) | Same initial drop but partial recovery to ~1.9 ×10⁴ by end | Weaker pushing force; less complete rupture |
| **Push control** (grey) | Flat at ~2.5 ×10⁴ throughout | No clamp → stem intact |
| **Pull + 54 nt** (blue) | Flat, indistinguishable from control | Pulling geometry does not rupture stem |
| **Pull + 40 nt** (red) | Same — flat, ~2.5 ×10⁴ | No rupture |
| **Pull control** (grey) | Flat ~2.6 ×10⁴ | Baseline |

**Key conclusion (Lab6):** Pushing clamps with 54 nt rod produce the largest fluorescence decrease (most stem opening). Pulling clamps have no detectable effect — consistent with simulations showing ΔF ≈ 0 for pulling and ΔF ≈ −6.8 kT for pushing.

### Lab3 — 12 nt stem, 54 nt and 27 nt rods (`FirstNanodevTest_Lab3_Final.m`)
Script: `fluorescence_kinetics_lab3.py` → `fluorescence_kinetics_lab3_push.pdf/svg`, `fluorescence_kinetics_lab3_pull.pdf/svg`, `fluorescence_kinetics_lab3_pull_legend.pdf/svg`

2 replicates per condition; mean ± 1 SD (half-range) shown; movmean window = 7.

| Condition | Observation | Interpretation |
|-----------|-------------|----------------|
| **Push + 54 nt** (blue) | Drop ~3.3 → ~2.8 ×10⁴ RFU after injection | Pushing disrupts 12 nt stem, but smaller effect than 6 nt |
| **Push + 27 nt** (red) | Similar drop, slightly smaller magnitude | Shorter rod = weaker force = less disruption |
| **Push control** (grey) | Flat / slight upward drift ~3.3 ×10⁴ | No clamp, gradual signal drift |
| **Pull** (all) | All lines flat and overlapping ~3.3 ×10⁴ | No disruption — pulling inactive on 12 nt stem too |

**Key conclusion (Lab3):** Longer stem (12 nt vs 6 nt) is harder to rupture — smaller fluorescence decrease despite same clamp geometry. Push still outperforms pull. The effect size is smaller for 27 nt vs 54 nt rod.

## Two-Window Umbrella Sampling

### HB Window (wX_s1 to wC_s10 in v5/)
- **op file:** `op-setA.txt` (bond OP + mindistance OP with `interfaces = 2., 6., 10., 14., 18., 22., 26., 30., 34.`)
- **Goal:** sample bond=6 (fully bonded) → bond=0 (fully melted), at small mindistance
- **wfile:** lists weights for bond=0–6, mindist_bin=0 (and/or 1); `default_weight=0` forbids all other states

### Distance Window (dist_wX_s1 to dist_wC_s10 in v5/)
- **op file:** `op-setA_dist.txt` (same pairs, but `interfaces = 2., 4., 6., 8., 10., 12.`)
  - 7 bins (0-2, 2-4, 4-6, 6-8, 8-10, 10-12, >12); max accessible distance ~11.4 oxDNA units
  - bin 5 (10-12) is the "fully separated" state; bin 6 was always zero in v5/v6
- **Goal:** sample mindist=0 → mindist=max (at bond=0 only)
- **wfile:** lists only bond=0 rows; `default_weight=0` forbids all bond>0 states
- **Starting conf:** a bond=0 configuration from v4 dist runs (NOT the relaxed bonded conf)
- **Observable (v7+):** all 6 stem pair distances (7 cols: step + d_pair1..d_pair6)
  - Post-process with min(col2..col7) to get true mindistance matching the OP
  - v5/v6 only had one pair (pair1) — useless for verifying mindistance

### Mindistance OP Geometry
The `mindistance` OP takes the MINIMUM distance among all listed pairs, NOT the maximum.
- The 6nt stem has 6 pairs connected by 42 nt of aptamer backbone when fully dissociated
- 42 nt fully extended ≈ 11.4 oxDNA units → geometric max mindistance ≈ 11.4
- bin 5 (10-12) catches this; bin 6 (>12) is now open in v7/v8 (weight=1) to verify
- Single-pair distances can reach 15-18 when mindistance=11 — NOT contradictory
- **Max observed mindistance (v8 dist_obs.dat, min of 6 pairs):**
  - Pulling: ~16.2 oxDNA units (~13.8 nm)
  - Pushing: ~16.7 oxDNA units (~14.2 nm)

### Connection Between Windows
Both windows share the state (bond=0, mindist_bin=0).

**Macrostate partition function approach (current):**
- Scale factor = U_HB(0,0) / U_dist(0,0) — both windows independently estimate the same P(bond=0, bin=0), so their ratio gives the relative normalisation
- Z_bonded = sum of unbiased counts for bond=1..6, mindist_bin=0 (from HB window)
- Z_ruptured = scale × sum of unbiased counts for bond=0, all mindist bins (from dist window)
- ΔF = −kT · ln(Z_ruptured / Z_bonded)
- Implemented in `free_energy.py`; run with `conda run -n oxDNA python free_energy.py`

**Previous approach (diagnostics.py, now deprecated for final ΔF):**
ΔG_total = ΔG_HB + ΔG_dist, connected at shared state bond=0, mdbin=0.

## Weight File Design

### Principle
Weights are proportional to 1/P_unbiased (flat histogram target).
Ideal weight: `w_new(s) = u_max / u(s)` where `u(s) = biased_count / w_old(s)` = column 4 of `last_hist.dat`.
Compute per combo (not pooled across combos), then average across combos.

### Format
```
<bond_count> <mindist_bin>  <weight>
0 0  1049
0 1  17.7
...
```
States not listed get `default_weight = 0` → forbidden.

### last_hist.dat Format
```
#t = ...; extr. Ts:
<bond> <mindist_bin> <biased_count> <unbiased_count>
```
Column 4 (`unbiased_count`) = biased_count / weight = the quantity used for free energy.

### energy.dat Format
Columns: `step  potential_E  col  col  col  bond_count  mindist_bin  weight`

**Key metrics per seed:**

- HB window: reference = (bond=6, mdbin=0), target = (bond=0, mdbin=0)

## Known Issues / Decisions Made
- **v4 convergence:** Most HB seeds ~1 round trip. Slow mixing in bond=0–2. v5 used 10 seeds + system-specific weights. v7 HB continues best 5 v4 seeds with init_hist.
- **Pulling bond=0 trap:** Some pulling seeds stuck at bond=0 — clamp holds strands apart. Expected.
- **v5 dist bin-pairing bug:** bins 1&2 had identical weights (17.7), as did bins 3&4. Wrong because they are separate bins. v7 derives weights per-bin from v5 data.
- **v5/v6 dist bin 6 blocked:** `default_weight=0` + no bin-6 entry = system forbidden from mindist>12. Can't verify geometric max. v7 fixes this by explicitly listing bin 6 with weight=1.
- **v6 abandoned:** dist runs started from wrong conf (last_conf.dat = bin=5, not bin=0). HB runs also started from wrong conf (bond=0). All v6 dist data is usable for diagnostics but not for production ΔG. v6 is in `v6/v6/` on cluster (nested due to sync issue).
- **v6 single-pair obs:** dist_obs.dat in v6 only had one pair distance, not mindistance. High single-pair distances (15-18) are not contradictory — when mindistance=11, other pairs can be far. v7 has all 6 pairs.
- **Pooling combos:** Compute w_ideal = u_ref/u(s) as a ratio WITHIN each seed (partition function cancels), then average across seeds. Averaging u values directly across combos is wrong.
- **Topology change:** v4/v5/v6/v7 all use the NEW topology. v3 used different indices. Always use pairs from the Nucleotide Indices table above.
- **v7 dist starting confs:** pulled from v4 dist runs (conf_1390000.dat etc.). Assumed to be bond=0, mindist≈0 since they were used as v5 dist starting confs. Provenance not fully verified.
