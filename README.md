# Re-Genesis
Repository for Y3 Imperial Bioeng Team (2025-26) supervised by Dr Thomas Ouldridge and Dr Max Earle.

## Using NUPACK
Replicating these results requires the python NUPACK library. Here, we use NUPACK v4.0.2.0 which requires Python ≥3.10. Our virtual environment specifically uses Python 3.13.

Instructions for installing can be found here: https://docs.nupack.org/start/
